User Guide & Workflows

System Workflows
1. Setting Up Your School

Start by going to Classes and adding your classes (e.g., JSS 1, SS 3). Once a class is created, you can add Subjects and enroll Students.

2. Academic Management

Navigate to a Class and click Manage Exams. Create an exam (e.g., First Term Exam). After creating it, use the Enter Marks button to fill in scores for all students in that class at once.

3. Attendance Tracking

In the Class Detail view, click Attendance. Select the date and toggle the switch for each student. Don't forget to click Save Attendance.

4. Fee Management

Go to the Fees dashboard. Here you can define fee structures for each class (e.g., Tuition Fee, Library Fee). Click Details next to a student to record a payment.

5. End of Term Promotion

Use the Promotion button in the Class Detail view to move students to the next class at the end of the academic year.
